IMPORTANT: THIS PACKAGE IS GITHUB-READY AFTER EXTRACTION.
DO NOT upload the ZIP file itself to GitHub.

For GitHub Pages:
1. Extract the downloaded ZIP on your computer.
2. Open the extracted folder.
3. Upload index.html and the complete manuals folder to the ROOT of your GitHub repository.
4. Keep the manuals folder name and all PDF filenames exactly as supplied.
5. In GitHub: Settings → Pages → deploy from the branch/folder containing index.html.
